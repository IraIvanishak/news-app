⏺ Unsplash API Exploration Summary

  API Capabilities ✓

  - Search by Text: /search/photos endpoint supports keyword-based search
  (perfect for article titles/content)
  - Flexible Filtering: Sort by relevance/latest, filter by color,
  orientation, content safety
  - Multiple Image Sizes: Returns URLs in various sizes (raw, full, regular,
   small, thumb)
  - Real-time Transformations: Can resize/crop images via URL parameters
  without API calls

  Technical Requirements

  Authentication:
  - Demo mode: Access Key only (HTTP Authorization header)
  - Production: OAuth2 available but not required for search/display

  Key Endpoint:
  GET https://api.unsplash.com/search/photos
    ?query={article_title_or_keywords}
    &per_page=10
    &orientation=landscape

  Response: JSON with photo URLs, photographer info, dimensions, color data

  Critical Constraints

  | Constraint            | Impact
                         |
  |-----------------------|-------------------------------------------------
  -----------------------|
  | Rate Limits           | Demo: 50 req/hour → Production: 5,000 req/hour
  (requires approval)     |
  | Hotlinking Required   | MUST use Unsplash CDN URLs - cannot
  download/rehost images             |
  | Attribution Mandatory | Must display photographer name + link to their
  profile with UTM params |
  | Download Tracking     | Must ping download_location endpoint when author
   selects a photo       |

  Integration Considerations for Your Stack

  Backend (Go/Fiber):
  - Add HTTP client for Unsplash API calls
  - Store only photo URL + attribution data in MongoDB Post model (not the
  image itself)
  - Create service to search photos and trigger download endpoint

  Frontend (HTML Templates):
  - Display photo suggestions during article creation (posts/create.html)
  - Show attribution (photographer name + Unsplash link) wherever photos
  appear
  - Handle photo selection and append to article form

  Data Model Changes:
  - Extend Post model with optional fields: PhotoURL, PhotoAttribution
  (photographer name, profile URL)

  Suitability Assessment: ✅ SUITABLE

  Pros:
  - Directly matches use case (search by title/keywords)
  - Free tier sufficient for small-medium sites
  - No cost per image
  - Server-side rendering compatible

  Cons:
  - Cannot cache/store images locally (must hotlink)
  - Attribution adds UI complexity
  - Demo rate limit (50/hr) requires production approval for real traffic
  - Need download tracking implementation

  Recommendation: This API is well-suited for your news site. The search
  functionality aligns perfectly with suggesting photos based on article
  content, and the hotlinking requirement actually simplifies your
  infrastructure (no image storage needed). Main considerations are
  attribution UI and applying for production rate limits before launch.

  Architecture Overview

  User Request → PostHandler → UnsplashService → Unsplash API
                      ↓               ↓
                  PostService    (transform data)
                      ↓
              PostRepository → MongoDB
                      ↓
                Template Rendering
